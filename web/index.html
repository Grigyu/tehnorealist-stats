Как это работает

  1. 01

    Обход ресурсов раз в час

    Сборщик проходит по реестру площадок и снимает показатели по каждому ресурсу.

  2. 02

    Официальные API и публичные страницы

    Только открытые источники: API платформ и страницы, доступные без входа.

  3. 03

    Запись снимка в базу SQLite

    Один снимок — одна запись с временем МСК и источником по каждому ресурсу.

  4. 04

    Публикация снимка на странице

    Свежий снимок вшивается в страницу при сборке — без запросов в момент открытия.

Учитываются только публично доступные показатели. Закрытые метрики не оцениваются и не додумываются. Время снимка — МСК.

* — последнее известное значение: площадка не отдаёт публичные счётчики, повторная проверка из среды сбора невозможна.

Источники: VK API, публичный API Дзена, Rutube API, HTTP-проверка страниц. Telegram и MAX публичные счётчики не отдают.
